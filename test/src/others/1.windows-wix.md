#### rpp requirements.

- [x] Need check the dirver integrality
- [x] Need check the environment
  - [x] Before installing the driver, it is necessary to confirm that the driver is fully compatible with the operating system version and hardware model
  - [x] Check whether the system is test mode or release mode. The signed driver can installed at test mode and release mode system, but the test driver can only installed at test mode system. If the system mode didn't match driver mode, promt to user, and ternimal this installation.
  - [x] Check host battery level, warn user if battery level too low.
  - [ ] Check if any application use the NPU device when installation. If yes, promt to user, and ternimal this installation.
- [x] Need prompt to user if need backup the user data
  - [x] The setting value of loglevel, working mode, etc.
- [x] Need create a system restore point
- [x] Need uninstall the old driver.
  [x] Uninstall the old version before install the new one. If there exists multiple drivers in system, uninstall them all.
    [x] Check the driver name and hardware id.
    [x] List all old version before uninstall them.
- [x] Need support install the new one and save the driver log.
- [x] Need prompt the result. If success, prompt to user to restart the driver. If failed, print the error reason and driver log.

#### Wix + C# learn.

- WiX通过使用XML来描述组件、功能和XML格式的.MSI文件中使用的各种对话框。 通过标签`<Package>` `<Feature>` `<Component>` `<Component>`
  `<File>` `<Shortcut>` `<RegistryValue>` `<Directory>` `<StandardDirectory>`安装产品的目录布局。
- 技术点: XML语法，WiX toolset模块及API的使用，项目模块拓展等。

2. Package.wxs WiX源文件结构。

```xml
<!-- Package.wxs, 根元素Wix，命名空间http://wixtoolset.org/schemas/v4/wxs -->
<Wix xmlns="http://wixtoolset.org/schemas/v4/wxs"></Wix>

<!-- 
Name: package name. 
Manufacturer: company name.
Version(16bit x 4): major.minor.build.patch major.minor.build major minor 
UpgradeCode: GUID(会被隐藏)
-->
<Package Id="TODO_Manufacturer.rpp_drv_package" Name="WixTutorialPackage" Manufacturer="TODO Manufacturer" Version="1.0.0.0" UpgradeCode="d73bcdbd-ee6b-4e71-a49f-ad33b96944a3"></Package>

<!-- 降级时打印的错误信息，阻止降级 -->
<MajorUpgrade DowngradeErrorMessage="!(loc.DowngradeError)" />

<!-- 功能入口 -->
<Feature Id="Main"></Feature>

<!-- 组件引用组 -->
<ComponentGroupRef Id="ExampleComponents" />
```

3. Folders.wxs WiX源文件结构。

```xml
<Wix xmlns="http://wixtoolset.org/schemas/v4/wxs"></Wix>

<!-- 声明WiX的一个片段 -->
<Fragment></Fragment>

<!-- 
Windows安装的标准目录
A Windows Installer standard directory. 
对于32bit的MSI包，ProgramFiles6432Folder被解析为C:\Program Files (x86)
对于64bit的MSI包，ProgramFiles6432Folder被解析为C:\Program Files
-->
<StandardDirectory Id="ProgramFiles6432Folder"></StandardDirectory>

<!-- 
其中!是取值的意思
bind.Property.Manufacturer获取的是Package.wxs中的Manufacturer 
bind.Property.ProductName获取的是Package.wxs中的name
-->
<Directory Id="INSTALLFOLDER" Name="!(bind.Property.Manufacturer) !(bind.Property.ProductName)" />
```

4. ExampleComponents.wxs WiX源文件结构。

```xml
<Wix xmlns="http://wixtoolset.org/schemas/v4/wxs"></Wix>

<Fragment></Fragment>

<!-- 作为一个组件，被Package.wxs引用 -->
<ComponentGroup Id="ExampleComponents" Directory="INSTALLFOLDER"></ComponentGroup>

<!-- 组件引用的文件 -->
<Component><File Source="ExampleComponents.wxs" /></Component>
```
